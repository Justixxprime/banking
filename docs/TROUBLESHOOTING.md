# Troubleshooting

If `npm start` says a module is missing, run `npm install`. If you see an old `better-sqlite3` binding error, run `npm install` again after pulling the current project files. If port 3000 is already in use, set another `PORT` value in `.env`. If you see `DATABASE_URL is missing`, create `.env` from `.env.example`. If start-up says it cannot connect, check the full Neon connection string and use `?sslmode=verify-full`; a sleeping Neon database can take a few seconds to wake. To reset the dev database, run the migration with `--replace`, or reset the Neon `dev` branch from the Neon console.
